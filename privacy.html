Privacy policy

This policy describes the personal-use Exocorder Claude Docs workflow maintained by JonBold11, and this informational website.

Purpose and information used

The workflow uses Claude Code and the local gws tool to carry out the operator’s requested Google Docs tasks. It can read a document’s title, structure, and contents, and send requested edits or report text to Google Docs. Google account identity information, including email and basic profile information, supports authentication.

The configured Google OAuth scopes are documents, openid, userinfo.email, and userinfo.profile. The Docs permission permits viewing, editing, creating, and deleting Google Docs accessible to the authorized account; it is not limited to one file. This configuration does not request Gmail, Calendar, or full Google Drive access.

Where information goes

The local gws process communicates with Google’s authentication and Docs services. When Claude Code reads command output or receives document content, that content can be sent to Anthropic for model processing as part of the Claude conversation. Generated text is sent to Google when the operator requests a document update.

This is not an entirely on-device workflow. Google and Anthropic process information under their respective terms, policies, and the operator’s account settings. This integration does not override those providers’ retention or model-training settings. See Google’s privacy policy and Anthropic’s privacy policy.

This website does not receive OAuth credentials or document content. The integration adds no advertising or analytics service and does not include a service for selling document data.

Storage and retention

In the installed configuration, gws stores OAuth credentials encrypted on the operator’s Mac and uses a local token cache. The OAuth client configuration is also stored locally. Document text or command output may remain in local terminal or Claude session records, and in the associated provider’s conversation records. Documents remain in Google Docs until managed or deleted there.

No fixed retention period or automatic deletion of those records is promised by this integration. Retention depends on the operator’s actions and the relevant application and provider settings.

Controls and deletion

The operator can stop using the workflow and revoke its Google access through Google Account connections. Revocation stops future access through that grant; it does not erase existing documents, published reports, or conversation and terminal records. Those must be managed separately in Google Docs, Claude, and local storage as applicable.

This website and contact

These static pages contain no sign-in form, tracking scripts, or analytics added by the maintainer. GitHub Pages hosts them and may process visitor connection information under the GitHub privacy statement. Following external links brings you to those services.

For questions, use the maintainer’s public GitHub profile or this repository’s issue tracker. Issues are public: do not post credentials, private document text, or other sensitive information. Policy changes will be published on this page with an updated date.

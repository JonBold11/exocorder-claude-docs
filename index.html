Personal-use integration

A document workflow for Claude Code.

Exocorder Claude Docs lets its operator ask Claude Code to read Google Docs or append a report using the locally installed gws command-line tool.

How it works

  1. The operator signs in with Google and grants the integration access to Google Docs.
  2. When asked to work with a document, Claude Code runs a local gws command that calls the Google Docs API.
  3. Requested document content can become part of Claude’s conversation. Reports can be sent back to Google Docs when the operator asks to publish them.

This is an individual’s personal workflow. This website provides information; it does not offer public registration or a browser-based document editor. The workflow does not automatically mirror terminal output.

Access and data handling

The Google permission covers viewing, editing, creating, and deleting Google Docs available to the authorized account. It is broader than access to one document. Basic Google identity scopes support sign-in; Gmail, Calendar, and full Google Drive access are not requested by this configuration.

Google handles document storage, and Claude processes content provided to it under the operator’s account settings and applicable terms. Read the privacy policy for storage, sharing, and revocation details.
